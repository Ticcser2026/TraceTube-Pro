Mesurer le rayon réel

  1. Effectue un cintrage d'essai avec le diamètre et la matière concernés.
  2. Repère les deux points où la partie droite commence réellement à se courber.
  3. Mesure le rayon sur l'axe du tube, ou relève-le à partir d'un gabarit adapté.
  4. Reporte cette valeur dans le calcul. Ne confonds pas rayon intérieur, extérieur et rayon à l'axe.
La calibration enregistrée par outil, diamètre et matériau sera ajoutée dans une prochaine version.

Installation sur iPhone

  1. Ouvre l'adresse web de l'application dans Safari.
  2. Touche le bouton Partager.
  3. Choisis Sur l'écran d'accueil, puis Ajouter.

Pour que l'installation et le mode hors connexion fonctionnent, le dossier doit être publié sur un hébergement HTTPS.
